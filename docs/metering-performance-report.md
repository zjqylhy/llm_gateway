# 计量性能修复第一阶段验收

日期：2026-10-11。使用场景：企业内部多个部门或应用共用网关。需求及技术方案已获确认；本报告供代码和测试结果人工确认。原始数值见 [metering-performance-results.json](metering-performance-results.json)。

## 实现与正确性边界

- Kafka 分区继续串行入账，仅合并已完成 SQL、Redis、outbox 释放及结算水位的 offset 提交。默认最多 32 条或 100ms，空闲时提交尾部；慢步骤下时间阈值在步骤之间检查。提交失败停止读取，退出尽力提交安全位置；代次变化仍由 broker 和 SQL ownership 拒绝旧 owner。强杀允许幂等重放，offset 不得领先结算。
- 已预留空间的财务 completed 事件直接锁定 attempt 预留，不争抢全局容量行；预留缺失或不足时回退原路径。事件哈希冲突、重复事件、跨应用归属及原容量上限继续校验。容量行改为先读锁，缺失时再创建，避免每次无变化更新。
- 明确使用 utf8mb4 且未显式关闭时启用 MySQL 驱动参数转义，减少 prepare/execute/close 往返；JSON 列传 UTF-8 字符串，二进制载荷仍传字节。其他字符集保留预处理。`interpolateParams=false` 可关闭；`GW_METERING_COMMIT_BATCH_SIZE=1` 可恢复逐条提交。
- 增加分阶段耗时、拒绝原因及提交批量指标和三个监控面板。新指标使用固定枚举，不增加应用或 attempt 标签。容量锁耗时包含查询/获取锁，不能等同纯锁等待或完整持锁时间；拒绝原因计数不能直接等同去重 HTTP 拒绝数。

没有增大在途槽位、修改配额算法或取消门禁。本阶段保留 app_id 隔离，不增加部门总预算或组织权限模型。

## 对照环境与突发样本

基线 `gw_acceptance_6e8030ba67b1` 使用优化前行为和诊断指标；最终源码运行 `gw_acceptance_8b1d7477b571`。两网关、单 worker、模拟上游；每网关/worker 1 CPU、256MiB，上游 1 CPU、128MiB。HTTP 每实例 128 并发，付费在途每实例 8；应用 outbox 64MiB、全局 512MiB，每次 started 最多预留 1MiB。配额 Redis 为 8MiB/AOF always/noeviction，缓存 Redis 为 4MiB/allkeys-lru。Kafka 三分区、单副本。

共享本机 MySQL/Kafka/etcd/Milvus 无专属 CPU/内存限额，其他应用同时运行。最终种子比基线多两个应用，突发期间这些应用无请求。各组是短时闭环突发，顺序运行且未重复统计置信区间，不能把差异全部归因于代码或推广为线上容量。

## 回归、失败记录与交付边界

真实基础设施验收 `gw_acceptance_e42f90b8a6ee` 的 30 项通过，约 73.6 秒：覆盖真实 MySQL JSON 特殊字符往返、全局容量行被锁时已预留完成事件仍能保存、并发相同事件幂等与跨应用拒绝，以及旧账本恢复、真实双 worker 重平衡和原容量限制。此后最后一次源码改动仅跳过 request 摘要的无效预留探测，已由完整 Go 与最终容器回归覆盖。

最终容器运行 9 项全部通过，约 206.4 秒：worker 组成员限制、周期核验报告、双网关 Token/金额争抢、四组突发及流协议、五组固定到达率、worker SIGKILL 后补账、Redis SIGKILL/AOF 恢复和网关流中崩溃保留 pending。全量 Go test（count=1）、vet、所有命令 build（GOMAXPROCS=4、-p 1）、gofmt、27 份 YAML/35 面板校验、Compose config --quiet 和 git diff --check 通过。

保留失败 `gw_acceptance_5009ca3cd9cb`：启用参数转义后 JSON 的字节参数被标记为 binary，MySQL 3144 拒绝。将所有 JSON 列的序列化参数改为字符串，新增中文、引号、反斜线、NUL、emoji 和含 SQL 文本的安全往返回归，再通过基础设施验收；未把前置失败列为通过。

本轮仅使用随机隔离数据库/topic/组/配置前缀/collection/Redis 和专用角色容器。现有应用未升级。周期详细核验仍暂停应用，核验中断后的自动接续、历史数据生命周期、云预发、真实厂商、Linux race、SQL 物理备份/PITR 和整节点故障仍待后续阶段。当前结果支持继续低流量预发验证，尚不支持宣布生产性能达标。

# 企业大模型网关需求规格

需求与技术方案已于 2026 年 10 月 9 日经用户确认。面向求职展示，按线上系统要求设计。交付 P0 与 P1，首批支持 DeepSeek、Qwen、OpenAI；当前先进行本地验证，真实凭据稍后配置。

## 接口与权限

数据面提供 `/v1/chat/completions`、`/v1/embeddings`、`/v1/models`。支持文本、SSE、工具调用及结构化输出；不执行工具，不接收多模态。每个模型声明能力、上下文和输出上限。不支持的参数明确拒绝。

管理面使用独立账号、会话及 RBAC。管理员管理应用、模型、路由、密钥和用户；开发者仅访问授权应用；成本角色访问报表。应用 API Key 只展示一次，存储摘要；厂商凭据加密保存。日志默认只保存元数据。

## 请求治理

请求先鉴权和校验能力，再做应用级全局 QPS、安全过滤、预算与配额检查。缓存命中仍计入 QPS。路由采用显式优先级或权重，先过滤权限和能力；同一模型别名使用稳定的灰度分组。

非流式总期限 60 秒，流式 120 秒，最多 3 次上游尝试。响应开始之前允许对可重试错误降级，开始之后禁止混入其他模型输出。客户端断开取消上游。所有 5xx 和流式异常中断记入故障，预期策略 429 单独统计。

## 缓存

语义缓存默认关闭，应用主动开启，仅用于单轮纯文本、无工具、非实时问答。应用、路由版本、模型版本、system prompt、生成参数构成隔离边界。支持 TTL、阈值及主动清除。敏感请求跳过缓存；安全过滤在缓存之前运行。只有完整成功的普通文本回答可写入缓存，日志关闭不意味着缓存不存储回答。

## 用量与预算

每次客户端调用生成 request_id，每次实际付费调用生成 attempt_id，包含内部向量化。失败、重试和降级分别记录。厂商 usage 为真实值，缺失时显式标为估算或待对账，不当作零费用。计量消费幂等，事件可重放，修正记录保留审计。

应用月度 Token 配额统计实际调用消耗。并发调用使用预占机制；结算释放预占并补正实际值。金额使用整数微单位，保存币种及生效价格版本。预算 80% 告警，100% 按应用配置仅告警或拒绝。报表按应用、部门、模型汇总，支持 CSV。

## P1 与运维

包括成本报表、配额、模型灰度、预算告警、异常突增检测、Prompt 安全规则及审计。灰度支持 10%、50%、100% 和人工回滚；达到最小样本量后按错误率/延迟回滚。安全规则为可配置检测，不承诺覆盖所有 Prompt 注入。

配置版本化发布，展示期望及实例生效版本。密钥吊销传播目标 3 秒。缓存服务故障绕过缓存；额度或持久化事件通道不可用时拒绝新付费调用。进程崩溃时未完成 attempt 保留为待核实，不能保证上游未返回的精确用量。

## 验收

1. 本地协议回归验证鉴权、SSE、tools、结构化输出、Embedding、错误响应与权限隔离。
2. 并发与故障测试验证预算预占、幂等入账、重试上限、流式中断、缓存隔离和配置传播。
3. 控制台验证创建应用、一次性密钥、模型配置、路由、灰度、日志与成本导出。
4. 容量验收使用可控上游，记录实例资源、流量组成、连接数和完整结果。普通转发 P50 <10ms、P99 <30ms；缓存路径单独统计 P95 <150ms。
5. 真实厂商回归与容器基础设施联调单独执行；未执行的项目不标为通过。99.95% 是持续运行 SLO，不以短期测试证明年度可用性。

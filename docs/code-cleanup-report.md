## 本轮清理

| 范围 | 删除或调整 | 判定依据 |
| --- | --- | --- |
| 管理接口 | 删除 `WithTimeout` 及 context 导入 | 全部入口和测试没有调用 |

| 集成验证脚本 | 丢弃未读取的 deletedKeys 返回值 | etcd 清理命令和退出码检查仍执行 |
| 编译约束 | 开启 `noUnusedLocals`、`noUnusedParameters` | 后续构建直接检查未使用局部项和参数 |

Go 检查使用官方 `deadcode` v0.52.0，对 Windows/amd64、Linux/amd64 的全部 cmd/internal 入口及测试执行调用图分析；清理后两种目标报告的不可达函数均为 0。另从 Windows 生产入口单独检查，排除测试引用掩盖无用函数，结果也为 0；以 AST 核对包级声明、全文检索复核候选的引用。分析工具安装在忽略的临时目录，项目 go.mod/go.sum 和前端依赖未变。

前端检查包含导入与局部项、导出引用和 CSS 类引用；脚本使用 PowerShell AST 核对变量及语法，部署配置沿用结构验证。调用图结果只适用于上述平台和入口；不能据此证明所有条件分支都必然有用。仅删除确认没有用途的项，避免把低频流程当成死代码。

清理不改变 Prepare/Redis 预占/Arm、容量等待、计费结算或对外接口行为。历史实验报告、迁移证据和独立架构文档不是运行代码，不作为无用逻辑删除。

# 应用调用监控规格

2026-10-11 用户确认增加应用成功 QPS、按错误码分类的失败 QPS 和限流上限；时间范围按用户补充调整为最近 24 小时内任意起止时间。

## 统计口径

- 客户端对 Chat、Embedding、Rerank 接口的调用只统计一次；内部付费尝试不重复计入。缓存命中、降级后成功属于成功。SSE 中断或计量收尾失败即使 HTTP 已为 200，也属于失败并带业务错误码。
- 已认证应用的参数错误、无权限、模型不可用、限流、治理拒绝等都进入失败指标。无效密钥无法归属应用，使用固定 `_unknown` 标签；实例并发满仍不读取正文，已能识别的应用可归属，无法识别则进入 `_unknown`。
- 限流沿用应用的全局令牌桶，QPS 配额耗尽返回 `429 app_qps_exceeded`。预算/Token 配额耗尽继续使用原有 `insufficient_quota`。上限 0 表示不限制，并非 0 QPS。
- 区间卡片采用 `increase(counter[区间])/区间秒数`，失败按 HTTP 状态码及业务错误码拆分。趋势使用 `rate(counter[1m])`，每分钟一个点；成功与分错误码失败趋势合并在同一张图，历史生效上限使用右轴；失败按 HTTP 状态码及业务错误码分曲线，可选择单个错误码下钻，总失败仅保留区间汇总卡片。最初一个趋势点的滑窗可涉及区间开始前一分钟。Prometheus 采样及 extrapolation 意味着 QPS 是估计速率，不是精确逐秒账本。

## 埋点与查询

新增 `gateway_calls_total{app,outcome,http_status,error_code,source}` 和 `gateway_app_qps_limit{app}`，保留既有指标。成功及固定失败维度初始化为零，避免某种错误首次出现时无法观察初始计数。错误码使用网关固定集合，不把上游文本或客户端输入当标签。source 标识一个注册表，先去重再汇总，避免 dev 模式的两端口共享指标时重复计数。

管理端新增 `GET /admin/app-traffic?app_id=...&from=RFC3339&to=RFC3339`，校验时间范围处于最近 24 小时且不超过 24 小时。省略时间默认为最近一小时。管理/成本角色可查看当前应用，开发者仅可查看自己拥有的应用；PromQL 由服务端生成并严格限制应用集合，不能传入任意查询表达式。

使用 `GW_PROMETHEUS_URL` 配置私有 Prometheus Base URL，管理端统一查询 gateway/admin 两个 job 的所有实例（按随项目提供的抓取配置），排除仅消费计量的 worker；支持 `api/v1/query` 和 `query_range`。查询受总期限、响应字节数、序列数及点数约束，失败、部分结果和缺失数据明确提示，不使用最近日志样本代替监控数据，也不将缺失曲线填为零。

## 展示与部署

运行概览增加独立应用调用监控区，可选最近 5 分钟/1 小时/6 小时/24 小时及自定义起止时间。按应用显示区间平均成功/失败 QPS、当前配置上限、历史上限趋势及错误码汇总。保持其他调用记录和成本页的时间筛选；配置上限与历史采样上限分别标示。

Grafana 增加应用筛选与成功/分错误码失败/历史 QPS 上限三个面板；控制台查询严格限制最长一日，不改变独立 Grafana 的其他历史面板范围。正式 Compose/Kubernetes 配置可连接已有 Prometheus。轻量部署不自动启用监控容器，未配置时控制台显示未接入。

## 2026-10-12 错误码下钻补充（用户确认）

失败趋势默认展示所选区间发生过的 HTTP 状态码及业务错误码组合，各组合使用独立颜色和图例，选择错误码后只筛选失败曲线，成功及历史上限曲线保留，刷新监控时保留各应用的下钻选择。成功与各错误码失败使用同一左轴；历史上限使用独立右轴，坐标与图例明确标示，避免被限流上限压平。后端 range 查询按 app/http_status/error_code 聚合，并以区间结束时刻固定的 increase 结果筛选活动错误；不逐点过滤零速率，也不补齐缺失采样。API 的 failure series 增加 http_status/error_code 字段，重复组合、未知错误码及不匹配的状态码拒绝返回部分监控数据；既有时间范围和权限约束保留。

使用 Prometheus 的 [@ end() 固定区间结束时间](https://prometheus.io/docs/prometheus/latest/querying/basics/#modifier)；仍维持查询超时、字节数和序列数限制，结果超过限制时提示选择单个应用。验收覆盖两种错误码独立曲线、SSE HTTP 200 失败、不匹配/重复标签拒绝、零值及断线保留和单码选择。
